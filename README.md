# Time Greeting Application

A simple Python application that generates personalized greetings based on the current system time.

## Features

- Detects the current system time
- Displays a greeting based on the time of day
  - Good Morning
  - Good Afternoon
  - Good Evening
  - Good Night
- Simple and lightweight command-line interface

## Technologies Used

- Python 3
- datetime module

## Installation

```bash
git clone https://github.com/PRANJALxDEVxAI/time-greeting-python.git
cd time-greeting-python
```

## Usage

```bash
python main.py
```

> Replace `main.py` with your actual Python file name if it is different.
